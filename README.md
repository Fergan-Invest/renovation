# Fargona Invest GIS

Laravel + Nuxt based GIS platform for combining Excel data with KML/KMZ map
features and showing investment object details on an interactive map.

## Target Stack

- Backend: Laravel API
- Frontend: Nuxt 3
- Database: MySQL 8 with spatial columns and spatial indexes
- Map: OpenLayers
- Imports: Excel, KML, KMZ

## First Milestone

Build an MVP that can import an Excel file and a KMZ/KML file, match rows to
map features, and display linked feature details when a user clicks an object
on the map.
